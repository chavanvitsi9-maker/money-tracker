# MoneyTracker - สมุดจดบันทึกรายรับ-รายจ่าย (High Speed & Efficiency Edition)

แอพพลิเคชั่นบันทึกรายรับ-รายจ่ายที่ออกแบบมาเพื่อ **เน้นความสะดวกรวดเร็วในการ "จดบันทึก" เป็นหัวใจหลัก (Ultra-Fast Entry)** พร้อมมุมมองสมุดบัญชีรายวัน (Daily Ledger), แถบสรุปสถิติแบบพับเก็บได้, คีย์ลัดเต็มรูปแบบ, ระบบคำนวณเลขอัตโนมัติ, รายการด่วน 1 คลิก และรองรับการใช้งานแบบ Offline (PWA)

---

## 🌟 จุดเด่นและฟังก์ชันเพื่อความรวดเร็วสูงสุด

### 1. ความเร็วในการป้อนข้อมูล (Fast Entry & Workflow Speed)
- **✨ Smart Natural Language Input (พิมพ์ประโยคเดียวจบ จัดหมวดหมู่ให้อัตโนมัติ)**:
  - ไม่ต้องคลิกเลือกหมวดหมู่เองอีกต่อไป! สามารถพิมพ์บอกรายการเป็นภาษาธรรมชาติได้ทันที เช่น:
    - `ข้าวกะเพรา 65` ➔ บันทึกเป็น "อาหารและเครื่องดื่ม", รายจ่าย, ฿65.00
    - `กาแฟ 50 โอน` ➔ ตรวจจับช่องทางชำระเป็น "โอนเงิน/แบงก์กิ้ง" ให้อัตโนมัติ
    - `เติมน้ำมัน 800 บัตรเครดิต` ➔ หมวดหมู่ "เดินทาง / ค่าน้ำมัน", ช่องทางบัตรเครดิต
    - `ได้เงินเดือน 35000` ➔ สลับเป็น "รายรับ", หมวดหมู่ "เงินเดือน" ให้อัตโนมัติ
    - `ออมเงิน 5000 โอน` หรือ `โอนเก็บ 3000` ➔ หมวดหมู่ "เงินออม / ลงทุน", ช่องทางโอนเงิน
    - `ถอนเงินออม 2000` หรือ `ดึงเงินเก็บมาใช้ 1000 โอน` ➔ หมวดหมู่ "ถอนเงินออม / ดึงเงินเก็บ", รายรับ, นำเงินกลับมาใช้จ่าย
    - `ข้าว 40+15` ➔ ถอดรหัสนิพจน์คณิตศาสตร์และคำนวณยอด ฿55.00 ทันที
  - **Live Preview Card**: แสดงการ์ดแสดงผลแบบ Real-time บอกหมวดหมู่, ยอดเงิน, ไอคอน และสถานะรายรับ/รายจ่าย ขณะกำลังพิมพ์
  - **Enter to Submit**: พิมพ์เสร็จกด `Enter` บันทึกลงสมุดบัญชีทันที พร้อมเปิดรับพิมพ์รายการต่อไปได้ทันทีโดยไม่ต้องใช้เมาส์
  - **Manual Override Friendly**: หากต้องการเปลี่ยนหมวดหมู่หรือประเภท สามารถคลิกปุ่มหรือกดคีย์ลัดด้านล่างเพื่อปรับเปลี่ยนได้ตลอดเวลา
- **🐷 ระบบจัดการเงินออมและวินัยการเงิน (Two-Way Savings & Drawdown System)**:
  - **ฝากเงินออม (Save Money)**: บันทึกโอนเงินเข้าบัญชีออมเงิน จะไม่นำไปปนกับรายจ่ายกินใช้จริง
  - **ดึงเงินออมกลับมาใช้ (Savings Withdrawal)**: เมื่อเงินไม่พอใช้ สามารถบันทึกดึงเงินเก็บกลับมาเป็นรายรับ (เงินไหลกลับเข้ากระเป๋า) พร้อมทั้งระบบจะ **หักลดยอดเงินออมสะสมคงเหลือ** ให้อัตโนมัติ เพื่อให้ยอดเงินออมตรงกับความจริงในบัญชีธนาคาร
  - **Live Savings Rate % บน Sticky Header**: แสดงแถบ "เงินออมสะสมคงเหลือสุทธิ" พร้อมเปอร์เซ็นต์อัตราการออมต่อรายรับแบบเรียลไทม์
  - **การ์ดวิเคราะห์วินัยการออม (Savings Health Tracker)**: ในเมนูกราฟและสถิติ มีการ์ดวิเคราะห์สุขภาพเงินออมพร้อม Progress Bar และประเมินเกณฑ์วินัยทางการเงิน (เช่น ≥20% ยอดเยี่ยม, 10-19% ดี)
  - **1-Click Presets**:
    - `🐷 โอนเงินออม ฿3,000`: บันทึกโอนเงินเข้าบัญชีเงินออมในคลิกเดียว
    - `💸 ถอนเงินออม ฿1,000`: บันทึกดึงเงินออมกลับมาใช้ในคลิกเดียว
- **1-Click Quick Presets (แถบบันทึกด่วนใน 1 สัมผัส)**:
  - บันทึกรายการประจำ เช่น กาแฟ, ข้าวแกง, BTS, เติมน้ำมัน, โอนเงินออม, ถอนเงินออม ได้ทันทีใน 1 คลิก ไม่ต้องกรอกฟอร์มซ้ำ
  - สามารถกดปุ่ม **"จัดการ"** เพื่อเพิ่ม/ลบรายการด่วนของตนเองได้อิสระ
- **Inline Math Calculator (คำนวณเลขในช่องจำนวนเงินทันที)**:
  - ช่องจำนวนเงินรองรับนิพจน์คณิตศาสตร์ เช่น `50+20` หรือ `120*2-10`
  - มีป้ายกำกับแสดงผลลัพธ์คำนวณแบบ Real-time (`= ฿70.00`) เมื่อกดบันทึกหรือเปลี่ยนช่อง ระบบจะคำนวณยอดรวมให้อัตโนมัติ ไม่ต้องสลับไปเปิดแอพเครื่องคิดเลข
- **Smart Category Auto-Detection (เดาหมวดหมู่อัตโนมัติจากบันทึก)**:
  - เมื่อพิมพ์ในช่องบันทึกช่วยจำ เช่น *"ข้าวกะเพรา"*, *"bts"*, *"น้ำมัน"*, *"shopee"* ระบบจะเลือกหมวดหมู่ที่เกี่ยวข้องให้อัตโนมัติทันที
- **คีย์ลัดเต็มรูปแบบ (Full Keyboard Shortcuts)**:
  - `Alt + 1` ถึง `Alt + 9`: เลือกหมวดหมู่ที่ 1 - 9 ทันที
  - `Alt + E`: สลับเป็น **รายจ่าย** 🔴
  - `Alt + I`: สลับเป็น **รายรับ** 🟢
  - `Enter`: บันทึกรายการ
  - `/` (Slash): โฟกัสไปที่ช่องค้นหารายการทันที
  - `M`: เปิด/ปิดเสียงตอบสนอง (Sound Feedback)
  - `Esc`: ยกเลิกโหมดแก้ไข / ล้างฟอร์ม / ปิดหน้าต่าง Modal
  - `?`: เปิดหน้าต่างสรุปคีย์ลัดทั้งหมด
- **Audio Feedback (เสียงตอบสนองนุ่มนวล)**:
  - สังเคราะห์เสียงผ่าน Web Audio API โดยตรง (0 latency, ไม่ใช้ไฟล์ภายนอก) ช่วยให้รับรู้การบันทึกสำเร็จได้ทันที สามารถเปิด/ปิดได้ที่ปุ่มกระดิ่งบนหัวเว็บ

### 2. ประสิทธิภาพทางเทคนิคและความเร็วในการโหลด (Performance & Offline PWA)
- **PWA Ready & Offline-First**:
  - มาพร้อม `manifest.json` และ `sw.js` (Service Worker) แคชไฟล์ระบบอัตโนมัติ
  - รองรับการติดตั้ง (Install) เป็น Desktop App บน Windows หรือ Home Screen บนมือถือ
  - ใช้งานได้แบบ **Offline 100%** แม้ไม่มีสัญญาณอินเทอร์เน็ต
- **Debounced Search**:
  - ระบบค้นหาแบบหน่วงเวลา (Debounce 180ms) พิมพ์ค้นหาได้ลื่นไหล ไม่กระตุกแม้มีข้อมูลนับพันรายการ
- **Ledger Pagination (โหลดประวัติแบบแยกวัน)**:
  - แสดงผลประวัติเริ่มต้น 15 วันล่าสุด พร้อมปุ่ม **"แสดงรายการเพิ่มเติม"** ช่วยลดภาระ DOM ทำให้หน้าเว็บเบาและตอบสนองเร็วอยู่เสมอ

### 3. การจัดการข้อมูลที่รวดเร็ว (Data Management)
- **ปุ่ม Duplicate / คัดลอกรายการ**:
  - ปุ่มไอคอนคัดลอกในแต่ละแถวรายการ ช่วยคัดลอกรายการเดิมมาเป็นของ **"วันนี้"** ได้ในคลิกเดียว
- **Daily Ledger Stream**:
  - จัดกลุ่มรายการแยกตามวัน (วันนี้, เมื่อวานนี้, วันที่ผ่านมา...)
  - สรุปยอดเงินเข้าและเงินออกของแต่ละวันให้เห็นชัดเจน
- **การเชื่อมต่อและซิงค์ Google Sheets (คลาวด์ตารางอัตโนมัติ คอลัมน์มาตรฐาน A-G)**:
  - เชื่อมต่อกับ Google Sheets โดยตรงผ่าน Google Apps Script Web App ฟรี 100%
  - บันทึกลงตารางมาตรฐาน: **A=วัน-เวลา, B=ประเภท, C=รายการ, D=หมวดหมู่, E=จำนวนเงิน (ตัวเลขคำนวณ =SUM() ได้), F=ช่องทางชำระ, G=รหัสอ้างอิง**
  - **Auto-Sync**: ทุกครั้งที่บันทึกรายการบนเว็บแอป ข้อมูลจะถูกส่งขึ้นชีตในพื้นหลังให้อัตโนมัติ
  - **Batch Upload & Pull**: มีปุ่ม "ส่งข้อมูลขึ้นชีต" และ "ดึงข้อมูลจากชีต" เพื่อผสานข้อมูลระหว่างอุปกรณ์ได้ตลอดเวลา
- **การส่งออกและสำรองข้อมูล**:
  - ส่งออกตาราง **Excel / CSV** (รองรับภาษาไทย UTF-8 BOM)
  - สำรองและกู้คืนข้อมูลผ่าน **JSON**
  - สั่งพิมพ์รายงานแบบพร้อมใช้งาน (Print-friendly)

### 4. หน้าสรุปและรายงานการเงินประจำเดือน (Monthly Summary & Expense Ranking Dashboard)
- **ระบบสลับแท็บหลัก (Main Navigation Tabs)**:
  - สลับระหว่าง **[ 📝 บันทึกรายวัน ]** (หน้าจดเร็ว + สมุดบัญชี) และ **[ 📊 สรุปและรายงาน ]** (หน้าแดชบอร์ดสรุปเต็มตา) ได้สะดวกรวดเร็ว
- **สรุปภาพรวมรายจ่ายประจำเดือน (Monthly Key Metrics)**:
  - สรุป **รายจ่ายเดือนนี้**, **รายรับเดือนนี้**, **คงเหลือสุทธิ**, และ **เงินออมสะสม** ชัดเจนใน 4 การ์ดหลัก
  - คำนวณ **ค่าเฉลี่ยรายจ่ายต่อวัน (Daily Average)** ให้เห็นทันที
- **🏆 จัดอันดับค่าใช้จ่ายตามหมวดหมู่ (มากสุด ➔ น้อยสุด)**:
  - จัดอันดับหมวดหมู่ที่มีการใช้จ่ายสูงสุดลงไปหาน้อยที่สุด พร้อมเหรียญรางวัล 🥇 #1, 🥈 #2, 🥉 #3
  - แถบ Progress Bar สัดส่วนสีสันตามหมวดหมู่ พร้อมยอดเงินและเปอร์เซ็นต์ (%)
  - การ์ดสปอตไลต์ **🥇 จ่ายเยอะที่สุด (Top Spender)** และ **🌱 จ่ายน้อยที่สุด (Lowest Spender)**
  - **Interactive Drilldown**: คลิกที่แถวหมวดหมู่เพื่อคลี่ดูรายการย่อยทั้งหมดในหมวดนั้นได้ทันที
  - ปุ่มสลับการเรียงลำดับ: เรียงตามยอดเงิน (มาก ➔ น้อย) หรือ เรียงตามความถี่จำนวนครั้ง
- **การวิเคราะห์อัจฉริยะ (Smart Financial Insights)**:
  - **พยากรณ์รายจ่ายสิ้นเดือน**: คำนวณจากอัตราการกินใช้วันต่อวัน เพื่อคาดการณ์ยอดเงินที่จะจ่ายถึงสิ้นเดือน
  - **วันที่จ่ายหนักที่สุด (Peak Spending Day)**: สรุปวันที่มียอดใช้จ่ายพุ่งสูงผิดปกติ พร้อมรายการหลัก
  - **ช่องทางชำระเงินหลัก**: สรุปช่องทางที่เงินออกมากที่สุด (พร้อมเพย์, บัตรเครดิต, เงินสด ฯลฯ)
- **กราฟและแผนภูมิวิเคราะห์**:
  - **Donut Chart**: สัดส่วนรายจ่ายแยกตามหมวดหมู่พร้อม Tooltip สวยงาม
  - **Daily Spending Bar Chart**: กราฟแท่งรายจ่ายรายวัน (วันที่ 1 - 31) เห็นแนวโน้มทั้งเดือน
  - **Top 5 Single Expenses**: สรุป 5 รายการจ่ายก้อนใหญ่ที่สุดในเดือน
- **ตัวเลือกสลับเดือนและพิมพ์สรุป**:
  - เลื่อนดู `< เดือนก่อนหน้า | เดือนนี้ | เดือนถัดไป >` หรือเลือกเดือน/ปีใดก็ได้ย้อนหลัง
  - ปุ่ม **"พิมพ์รายงาน"**: จัดหน้าสำหรับพิมพ์ใบสรุปยอดการเงินประจำเดือนได้อย่างสวยงาม

## 🚀 วิธีเปิดใช้งาน

1. **ดับเบิลคลิกไฟล์ `run_app.bat`**: เปิดใช้งานผ่าน Windows ได้ทันที พร้อมรัน Local Server
2. **ดับเบิลคลิกไฟล์ `index.html`**: ดับเบิลคลิกเปิดผ่าน Chrome, Edge หรือเบราว์เซอร์ใดก็ได้โดยตรง
3. **รันคำสั่ง `py server.py`**: เปิด Local Web Server พร้อมเปิดหน้าเว็บให้อัตโนมัติที่ `http://localhost:8000`
